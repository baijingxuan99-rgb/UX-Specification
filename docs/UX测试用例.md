# UX测试用例（82条）

## L1 玩家行为

### T01 · 首次进入 · P0

- 前置状态 / 触发条件：新号，未开启引导
- 玩家任务：进入游戏，开始你的第一次战斗
- 通过标准：能找到主目标；不被活动或次要入口干扰；理解当前操作
- 观察指标：入口首击、求助、耗时

### T02 · 新手引导 · P0

- 前置状态 / 触发条件：新号，引导进行中
- 玩家任务：完成第一段教学，并尝试自己进行下一次挑战
- 通过标准：理解机制；可识别引导结束；后续可独立操作
- 观察指标：是否复述规则、是否依赖引导

### T03 · 主界面 · P0

- 前置状态 / 触发条件：已解锁多个系统
- 玩家任务：你只有三分钟，想让角色变强并继续推进
- 通过标准：能辨识主线与养成入口；合理选择提升方式
- 观察指标：首击、路径、绕路

### T04 · 开始战斗 · P0

- 前置状态 / 触发条件：体力充足，有可挑战关卡
- 玩家任务：挑战下一关
- 通过标准：关卡、消耗、推荐信息清楚；启动后有明确反馈
- 观察指标：首击、操作次数

### T05 · 战斗准备 · P0

- 前置状态 / 触发条件：多套装备或功法
- 玩家任务：在开战前调整你的战斗配置
- 通过标准：当前配置清楚；变更后生效；返回关卡无迷失
- 观察指标：回退、变更理解

### T06 · 战中选择 · P0

- 前置状态 / 触发条件：出现技能三选一
- 玩家任务：选择一个你认为适合本局的能力
- 通过标准：理解选项差异及效果；选中与生效明确；不遮挡必要战况
- 观察指标：选择理由、误选

### T07 · 战中暂停 · P0

- 前置状态 / 触发条件：允许暂停的战斗
- 玩家任务：暂时离开战斗，稍后继续
- 通过标准：暂停和继续入口清楚；离开代价提前告知
- 观察指标：误退、是否找回

### T08 · 战斗胜利 · P0

- 前置状态 / 触发条件：关卡完成
- 玩家任务：确认本次战斗收获，并继续下一关
- 通过标准：胜利、奖励、解锁清楚；下一步突出；返回可达
- 观察指标：奖励复述、停顿

### T09 · 战斗失败 · P0

- 前置状态 / 触发条件：设置为失败结算
- 玩家任务：你没打过这一关，想提高胜率后再挑战
- 通过标准：失败原因或可执行建议明确；养成跳转和回关卡闭环
- 观察指标：选择、迷失、闭环

### T10 · 强化角色 · P0

- 前置状态 / 触发条件：资源足够
- 玩家任务：用现有资源提升角色战力
- 通过标准：找到升级功能；消耗、提升、结果清楚
- 观察指标：首击、成本复述

### T11 · 资源不足 · P0

- 前置状态 / 触发条件：升级材料不足
- 玩家任务：想升级，但现有材料不够；请继续想办法
- 通过标准：识别缺哪种、差多少、获得途径；回来保持原任务
- 观察指标：跨系统路径、理解

### T12 · 装备替换 · P0

- 前置状态 / 触发条件：有两件属性不同的装备
- 玩家任务：选择一件更适合当前角色的装备
- 通过标准：识别当前装备、差异、替换影响；操作可控
- 观察指标：比较正确性、误换

### T13 · 批量养成 · P1

- 前置状态 / 触发条件：多个可升级项目
- 玩家任务：尽量快速完成一轮提升
- 通过标准：批量范围、消耗、结果清晰；可避免误花稀缺资源
- 观察指标：操作次数、误耗

### T14 · 背包道具 · P1

- 前置状态 / 触发条件：背包含多类材料与消耗品
- 玩家任务：找到一个指定材料，看看它有什么用途
- 通过标准：分类或筛选可理解；数量、用途、来源清晰
- 观察指标：查找耗时、试错

### T15 · 道具使用 · P1

- 前置状态 / 触发条件：有可选择数量的箱子
- 玩家任务：只使用其中两个箱子
- 通过标准：数量选择准确；预览、确认、剩余数量明确
- 观察指标：误耗、次数

### T16 · 招募抽取 · P0

- 前置状态 / 触发条件：有免费和付费资源
- 玩家任务：使用一次免费的招募机会，不花付费货币
- 通过标准：清楚免费资格与付费区别；结果与余额可查
- 观察指标：误付费、成本理解

### T17 · 日常任务 · P0

- 前置状态 / 触发条件：含未完成、可领奖任务
- 玩家任务：领取已完成的任务奖励，并完成一项剩余任务
- 通过标准：任务状态分明；前往路径与返回路径正确
- 观察指标：领取后状态、迷失

### T18 · 离线收益 · P1

- 前置状态 / 触发条件：离线收益待领取
- 玩家任务：回到游戏，查看并领取离线收益
- 通过标准：收益时间、上限、领取方式清楚；可拒绝附加广告
- 观察指标：理解、关闭误触

### T19 · 活动系统 · P1

- 前置状态 / 触发条件：多个活动，含倒计时
- 玩家任务：找到一个你现在还能参加并有奖励的活动
- 通过标准：入口、参与条件、剩余时间、奖励及领取清楚
- 观察指标：活动选择理由

### T20 · 商城兑换 · P0

- 前置状态 / 触发条件：免费、限购和付费商品并存
- 玩家任务：找一个可免费领取的商品，不进行付费购买
- 通过标准：免费、价格、限购及货币明确；无诱导误购
- 观察指标：误购、状态理解

### T21 · 邮件领取 · P1

- 前置状态 / 触发条件：多封邮件含附件及已领取项
- 玩家任务：领取所有可领取的附件
- 通过标准：一键领取范围、领取结果、未读状态清晰
- 观察指标：是否漏领、次数

### T22 · 红点清理 · P1

- 前置状态 / 触发条件：主界面多个红点
- 玩家任务：找出有哪些实际可以完成或领取的事情
- 通过标准：红点有明确原因；完成后同步消除；无循环跳转
- 观察指标：误导、残留

### T23 · 跨系统回流 · P0

- 前置状态 / 触发条件：从升级材料不足开始
- 玩家任务：取得缺少的材料，再回到原升级位置
- 通过标准：跳转目的明确；原页签、目标及必要上下文可恢复
- 观察指标：回流成功、额外步数

### T24 · 中断恢复 · P0

- 前置状态 / 触发条件：弹窗或养成页中断
- 玩家任务：模拟切后台，再回来继续刚才的操作
- 通过标准：知道当前状态；不重复扣费或领奖；可继续或退出
- 观察指标：恢复理解、重复操作

### T25 · 设置与退出 · P1

- 前置状态 / 触发条件：已进入游戏
- 玩家任务：关闭音效，再回到原先的界面
- 通过标准：设置入口易找；音效开关状态清楚；设置保存
- 观察指标：寻找、返回

### T26 · 付费取消 · P0

- 前置状态 / 触发条件：模拟商城订单确认
- 玩家任务：看看礼包价格，再取消购买
- 通过标准：真实价格、币种和内容明示；取消不扣费；可回原位置
- 观察指标：误支付、取消成功

- 前置状态 / 触发条件：同时触发奖励、解锁、活动提示

- 前置状态 / 触发条件：请求开始至完成
- 通过标准：提供加载反馈；不将加载误显示为空

- 前置状态 / 触发条件：少量及常规数据

### S05 · 按钮 / 不可用 · P0

### S07 · 养成 / 资源不足 · P0

### S09 · 养成 / 满级/满星 · P0

- 前置状态 / 触发条件：达到等级或突破上限

### S10 · 养成 / 条件组合 · P0

### S11 · 装备 / 无装备/已装备 · P1

- 前置状态 / 触发条件：完成或领取触发转换

### S14 · 活动 / 未开启/进行中 · P1

- 前置状态 / 触发条件：到达活动开始时间

### S19 · 付费 / 结果未知/延迟 · P0
