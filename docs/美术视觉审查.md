# 美术视觉审查 V1.1

适用单张竖屏游戏 UI 截图。独立入口 visual.html。
1. 拖入 PNG/JPG/WebP；填写页面目标、预期焦点。
2. 给元素框选 L1 核心、L2 决策、L3 辅助、L4 装饰。各标签是设计意图，不是算法结论。
3. 对照原图、灰度、模糊、相对显著性热图和九宫格；可加载第二张截图作双图对照（再次点击双图对照可更换对比图）。
4. 根据已标注区域的相对显著指数、边缘示意和原用例自查清单，确认问题及优化方向。无需硬性追求指数排名；战斗界面可有多个核心。
5. 导出 Markdown 修改报告和 JSON 标注记录。当前截图和编辑状态仅本次打开页面保留；导出不包含截图，不自动写回测试工作台。

显著性采用下采样后的局部边缘差、全图平均亮度偏差、通道颜色差加权并按本图 P95 归一化。高指数不等于玩家注意或可读性，不能跨图直接比较。非眼动预测、不识别文字或按钮语义、不能证明交互通过。安全区为示意；真实设备和多状态测试仍使用原 82 条用例。单图自查结论只适用于当前图。
